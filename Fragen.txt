dgels: 
hier geben wir also eine Matrix A rein und einen Vektor b (und noch weitere Infos) und dgels überschreibt unseren Vektor b:
wir haben die folgenden Eingabeparameter: 
order: storage layout ('row-major' or 'column-major').
trans: specifies whether the matrix should be transposed.
M: number of rows (of the matrix A) 
N: number of columns (of the matrix A)
nrhs: number of right-hand sides. (i.e., the number of columns of the matrices B and X. NRHS >=0)
Erklärung: A * X = B (mit A Matrix, X unbekannt und B Vektor) --> für wie viele verschiedene Ziel-Vektoren soll die Rechnung gleichzeitig in einem Durchlauf gelöst werden? --> 1: berechne für genau eine Person (wir haben genau eine rechte Seite) 
A: input array A. (on entry: the M-by-N matrix A, On exit, A ist overwritten)
hier ist wichtig: A wird überschrieben:
M >= N (mehr Zeilen als Spalten) -> A wird mit Details seiner QR_Zerlegung überschrieben
M < N -> dafür gäbe es eine andere Methode namens LQ-Zerlegung (DGELQF) --> hier irrelevant
LDA: leading dimension of A.
B: input array B. (HIER WIRD ES SPANNEND) (on entry: the matrix B of right hand side vectors, stored columnwise and on exit ...)
hier wird also auch B überschrieben:
if INFO = 0 (= 0:  successful exit), B is overwritten by the solution vectors, stored columnwise
if TRANS = 'N' (wir drehen die Matrix nicht um) and m >= n (mehr Zeilen als Spalten), rows 1 to n of B contain the least squares solution vectors; the residual sum of squares for the solution in each column is given by the sum of squares of elements N+1 to M in that column; 
if TRANS = 'N' and m < n, .... irrelvant für uns
--> hier also wichtig für uns: vorher stand in b: [SNP0_abweichung, SNP1_abweichung, ....., SNP(numSNPs-1)_abweichung] und danach: [PC1_koordinate, PC2_koordinate, ..., PC(numPCs)_koordinate, Restfehler_Komponente_N, ..., Restfehler_Komponente_M-1]
LDB: leading dimension of B.
